Part 1 // Candidate Challenge Formulations (RFC Drafts)

RFC-2026-01 Maritime Logistics
Constrained Port Berth & Quay Crane Assignment via QAOA
min H_C(x) = ∑ c_ij x_ij + λ_1 ∑ (∑ x_ij - 1)² + λ_2 H_tide(x)
Classical Baseline: Gurobi 11.0 Branch-and-Cut MILP (chokes at N > 45 concurrent vessel arrivals)
Target Hardware: Trapped-Ion (IonQ Forte / Aria, all-to-all connectivity, 0-SWAP routing)
Target Benchmark: -14.8% transshipment re-handling latency under monsoon arrival variance
RFC-2026-02 Financial Risk
Value-at-Risk (VaR) Acceleration via Quantum Amplitude Estimation (QAE)
P(|S_T - K| > θ) with quadratic speedup O(1/ε) vs classical Monte Carlo O(1/ε²)
Classical Baseline: Classical Monte Carlo (100,000 asset paths, 6.2 hours batch compute)
Target Hardware: High-Fidelity Trapped-Ion / Logical Qubit Simulator
Target Benchmark: Sub-minute convergence to ε = 10⁻⁴ accuracy for 10,000 multi-asset derivatives
RFC-2026-03 Biopharma & Chemistry
Continuous Lie-Algebra SO(3)/SU(2) Torsion for Molecular Active Site Docking
U(θ) = exp(-i ∑ θ_k G_k), where G_k ∈ su(2) ⊕ so(3) generate continuous spatial torsion
Classical Baseline: AutoDock Vina / smina heuristic spatial grid sampling
Target Hardware: Trapped-Ion Continuous Gate Sets (Project Q-Rotate)
Target Benchmark: 0-SWAP gate fidelity on non-abelian rotation manifolds for kinase inhibitor binding
RFC-2026-04 Post-Quantum Cryptography
Enterprise NIST FIPS 203 (ML-KEM) & FIPS 204 (ML-DSA) Migration Framework
Module Learning with Errors (M-LWE) & Module Short Integer Solution (M-SIS)
Classical Baseline: RSA-4096 / ECDSA P-384 legacy PKI infrastructure
Target Hardware: HSM Hybrid Key Encapsulation (CAVP A7970 Validated Stacks)
Target Benchmark: Zero-downtime TLS 1.3 / IPsec tunnel handshake negotiation under < 12ms latency overhead

Part 3 // Technical Architecture: The Triad

To translate quantum computing into practical engineering utility in Singapore, three independent components must align around reproducible benchmarks:

  • 1. Problem Owners (Maritime, Fintech, Energy): Formulating combinatorial bottlenecks that choke classical integer programming.
  • 2. Hardware & Compiler Vendors (IonQ, AWS, Horizon): Providing QPU access and native gate optimization passes.
  • 3. Sovereign Research & Capital (NRF, NQO, A*STAR, CQT): Establishing rigorous classical baselines and microchip fabrication.
