Brief 01 // Ingestion & Mathematical Modeling
Industrial Problem-to-QUBO Compilation & Hamiltonian Ingestion Pipeline
Track: Mathematical Formulation & Compilation | Sector Case: Maritime & BESS Grid Dispatch
Option 1 Active
1. Executive Context & Problem Statement
Industrial problem owners (PSA port berthing, EMA grid-scale BESS storage, logistics networks) express operational bottlenecks in Mixed-Integer Linear Programming (MILP) format. To execute on quantum annealers or variational circuits (QAOA/VQE), these constraints must be mapped into Quadratic Unconstrained Binary Optimization (QUBO) matrices or Pauli-$Z$ Ising Hamiltonians. If penalty multipliers ($A, B$) are miscalibrated, the quantum solver converges to mathematically invalid, infeasible states. Learners build an automated ingestion and compilation pipeline that validates problem schemas, synthesizes exact quadratic penalty budgets, and verifies solution feasibility against classical SOTA solvers.
2. Learner Deliverables & Technical Scope
● Constraint Ingestion & Normalization: Ingests JSON/tabular operational inputs (decision variables, inequality bounds, coupling matrices).
● Automated Penalty Multiplier Synthesis: Computes analytical lower bounds on penalty coefficients $A \gg B$ to guarantee forward invariance of the feasible set.
● Classical Baseline Solver Harness: Solves identical problem instances using Gurobi 11.0 / COIN-OR CBC to record baseline runtime, memory footprint, and optimality gaps.
● Quantum Hamiltonian Generation: Emits validated Qiskit / PennyLane / OpenQASM Hamiltonians with minimum ancilla slack bit overhead.
3. Bi-Weekly Delivery Rhythm
Sprint 1 Weeks 1–2
Ingestion & Schema Contracts
Define Pydantic data contracts for MILP constraints; build ingestion pipeline; reject malformed inputs; establish Gurobi classical baseline.
Sprint 2 Weeks 3–4
Penalty Synthesis & Slack Reduction
Implement analytical penalty multiplier calculation; minimize slack variables via logarithmic encoding; verify no false-positive ground states.
Sprint 3 Weeks 5–6
Service Encapsulation & Showcase
Package as an installable Python package/CLI; generate benchmark comparison plots against classical baselines; present live 45-min demo.
4. Suggested Tooling & Stack
Python 3.11+ Qiskit Optimization PennyLane Gurobi 11.0 / SciPy Pydantic v2 GitHub Actions
Brief 02 // Quantum Runtime & Telemetry
QPU Telemetry & Noise Mitigation Triage Pipeline
Track: Operations & Decision Intelligence | Sector Case: Singapore Quantum Stack Telemetry
Option 1 Active
1. Executive Context & Problem Statement
In real-world quantum hardware operations (IonQ, CQT trapped-ion, AWS Braket), physical parameters drift across calibration cycles—energy relaxation ($T_1$), dephasing ($T_2$), two-qubit gate fidelities, and readout crosstalk fluctuate dynamically. Submitting variational circuits without checking calibration health wastes cloud budgets and yields pure noise. Learners build an anomaly triage pipeline that monitors hardware telemetry, scores calibration drift anomalies, and routes quantum jobs through appropriate error mitigation (ZNE / PEC) or gracefully triggers classical failover.
2. Learner Deliverables & Technical Scope
● Calibration Telemetry Ingestion: Ingests daily QPU calibration snapshots (qubit graph topology, error matrices, coherence time-series).
● Statistical Anomaly Scoring: Detects multi-qubit crosstalk spikes, coherence degradation, and gate error outliers using rolling z-scores and IQR bounds.
● Automated Mitigation Routing: Routes quantum circuits based on severity: (1) Direct Execution, (2) Zero-Noise Extrapolation (ZNE), (3) Probabilistic Error Cancellation (PEC), or (4) Classical Solver Fallback.
● Audit Trail & Telemetry Feed: Emits verifiable JSON execution manifests with estimated circuit success probabilities (ESP).
3. Bi-Weekly Delivery Rhythm
Sprint 1 Weeks 1–2
Telemetry Modeling & Ingestion
Ingest synthetic and real QPU calibration logs; establish normal operating baselines; build rule-based and statistical anomaly detectors.
Sprint 2 Weeks 3–4
Triage Matrix & Error Mitigation
Build severity-scoring engine; integrate Mitiq ZNE/PEC pipelines; suppress false-positive alarms on transient calibration jitter.
Sprint 3 Weeks 5–6
Service Encapsulation & Showcase
Expose triage API; run synthetic drift injection stress tests; provide reproducible audit logs for live demonstration.
4. Suggested Tooling & Stack
Python 3.11+ Mitiq (Error Mitigation) Qiskit Aer / FakeBackends NumPy / SciPy FastAPI / Typer CLI Pytest
